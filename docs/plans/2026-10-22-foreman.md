# Foreman Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `foreman` Claude Code plugin: orchestrator guard, model-tiered subagents, a typed memory knowledge base with hooks and a `mem` CLI, and evidence enforcement.

**Architecture:** One plugin repo that is also its own marketplace.
- All hooks go through one stdlib-only Python entry point, `scripts/foreman_hooks.py <hook>`, which fails open.
- Memory logic lives in `scripts/memory.py`, shared by the hooks and the `mem` CLI.
- Agents and skills are Markdown.

**Tech Stack:** Python ≥ 3.12 stdlib only (run via `uv run --no-project --script`), pytest (tests only, via `uv run --with pytest`), Claude Code plugin format (v2.1.303).

**Spec:** `docs/specs/2026-10-22-foreman-design.md`

## Global Constraints

- Hook and CLI code: Python stdlib only, `# /// script` header with `requires-python = ">=3.12"` and `dependencies = []`.
- Hook command form: `uv run --no-project --script "${CLAUDE_PLUGIN_ROOT}/scripts/foreman_hooks.py" <hook>`.
- **Every hook fails open.** On any exception it writes the traceback to stderr, prints nothing to stdout and exits 0.
- "Allow" = exit 0 with empty stdout. Every hook output is one JSON object on stdout.
- Memory entry format, fields and enums exactly as spec §6.2. `stale_after` is required for `project` and `reference`, as a `YYYY-MM-DD` date or `never`.
- Index line: `- [<name>](<file>) — <description>`, traps prefixed `TRAP: `. The index holds at most 200 lines and 25,000 bytes.
- `SubagentStart` trap summary is at most 2,000 characters.
- Guard deny reason, verbatim: `Orchestrator doesn't edit project files: dispatch a subagent (see foreman:orchestrating), or set FOREMAN_SOLO=1.`
- Evidence block reason, verbatim: `Add ## Evidence and ## Unverified sections.`
- Agent models/efforts exactly as in spec §5.2.
- Plugin name `foreman`; marketplace name `foreman`; repo `vdtongdev/foreman` (private).
- Run all tests: `uv run --with pytest pytest -q` from the repo root.

## Review Focus

1. **A memory folder that doesn't exist yet.** New project, first write: `mem` and the hooks must create or ignore it, never crash. Pinned in Task 2 (`test_load_layer_missing_dir`).
2. **Drive-letter case.** `C:` vs `c:` must resolve to the existing `c--…` folder, not a second one. Pinned in Task 2 (`test_project_dir_matches_existing_case_insensitive`).
3. **Windows paths in hook input.** `tool_input.file_path` with backslashes must still match memory folders and trap globs. Pinned in Task 4 (`test_guard_allows_memory_path_with_backslashes`) and Task 6 (`test_trap_glob_matches_backslash_path`).
4. **Malformed hook stdin** (empty, non-JSON). It must allow, not crash. Pinned in Task 1 (`test_bad_stdin_fails_open`).
5. **Hand-edited memory entry with a frontmatter syntax error.** It must be reported, and the rest of the layer still indexed. Pinned in Task 3 (`test_index_skips_invalid_entry`).

## File structure

```
.claude-plugin/plugin.json         manifest (name, version, description, author)
.claude-plugin/marketplace.json    marketplace "foreman" listing plugin "foreman" at source "./"
hooks/hooks.json                   all hook registrations
scripts/memory.py                  frontmatter parse, Entry, validate, layers, index, links, select, CLI main()
scripts/foreman_hooks.py           dispatcher + one function per hook
bin/mem, bin/mem.cmd               CLI launchers (bash / cmd)
agents/{scout,drafter,implementer,verifier,expert}.md
skills/{orchestrating,memory,verifying}/SKILL.md
tests/conftest.py                  run_hook(name, payload, env) helper, tmp layers
tests/test_*.py
```

### Task 2: Memory model: parse, validate, layer paths

**Files:**
- Create: `scripts/memory.py`, `tests/test_memory_model.py`

**Interfaces:**
- Produces, in `memory.py`:
  - `parse_frontmatter(text: str) -> tuple[dict, str]`: returns (meta, body). It supports `key: value`, one nested mapping level (`metadata:`), inline lists `[a, b]`, `# comments` and quoted strings. It raises `ValueError("line N: ...")` on anything else.
  - `@dataclass Entry(name, description, type, trap: bool, paths: list[str], topics: list[str], status, superseded_by: str | None, verified, verified_on: str, stale_after: str, body: str, file: Path)`
  - `load_entry(path: Path) -> Entry`, which raises `ValueError`
  - `validate(entry: Entry, names: set[str]) -> list[str]`: problems, each prefixed `<file>: `
  - `user_dir() -> Path`: `Path.home()/".claude"/"memory"`
  - `project_dir(cwd: Path) -> Path | None`:
    - Takes the git common dir's parent (main worktree root).
    - Builds the slug by replacing each of `:`, `\`, `/` and space with `-`.
    - Returns the existing folder under `~/.claude/projects/` whose name matches the slug case-insensitively, else `<projects>/<slug>`, with `/memory` appended.
    - Returns `None` outside git.
    - The home directory can be overridden via the `FOREMAN_HOME` env var for tests.
  - `load_layer(dir: Path) -> tuple[list[Entry], list[str]]`: entries and parse errors, skipping `MEMORY.md`. A missing dir → `([], [])`.

### Task 3: Index, link rewriting, selection

**Files:**
- Modify: `scripts/memory.py`
- Create: `tests/test_memory_index.py`

**Interfaces:**
- Consumes: Task 2.
- Produces:
  - `render_index(entries: list[Entry]) -> str`: active entries only, traps first, then by type order `user, feedback, project, reference`, then name. Format per Global Constraints. When over 200 lines or 25,000 bytes, it truncates and ends with `- … <n> more: run mem select`.
  - `rewrite_superseded(dir: Path, entries: list[Entry]) -> list[str]`: rewrites `[[old]]` → `[[new]]` in bodies, following chains, and returns the changed file names.
  - `dangling_links(entries: list[Entry]) -> list[str]`: `"<file>: [[x]]"`.
  - `refresh_layer(dir: Path) -> list[str]`: load → rewrite → validate all → write `MEMORY.md` (skips invalid entries) → returns the problems.
  - `stale(entries: list[Entry], today: date) -> list[Entry]`
  - `select(entries: list[Entry], paths: list[str], topics: list[str], type: str | None, traps_only: bool) -> list[tuple[Entry, str]]`: (entry, reason). An entry with no paths/topics only matches when no filters are given. Path globs: `**` spans dirs, `*` within one. Paths are normalized to forward slashes and made repo-relative by the caller.

  - `test_stale_excludes_never_and_future`
